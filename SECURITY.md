# Безопасность и приватность

TouTou читает данные ваших аккаунтов Cursor и ChatGPT, поэтому ниже описано, что именно он делает, а что — никогда.

## Что приложение делает

| Действие | Как | Куда уходят данные |
|---|---|---|
| Лимиты Cursor | Читает токен из локальной базы Cursor (`state.vscdb`, режим **read-only**), выполняет `GET https://cursor.com/api/usage-summary` | Только на `cursor.com`; перенаправления запрещены |
| Лимиты ChatGPT / Codex | Запускает установленный `codex app-server` и вызывает `account/rateLimits/read` | Только локальный процесс Codex; новые чаты не создаются |
| События агента | Cursor hooks пишут JSON в `~/Library/Application Support/TouTou/events` | Никуда; нет сетевого сервера |
| Режим «Не спать при закрытой крышке» | `pmset -a disablesleep 1/0` через системный запрос пароля администратора | Локально |
| Режим «Не спать, пока агент работает» | `/usr/bin/caffeinate -i`, пока хуки видят `working` | Локально; пароль не нужен |

## Чего приложение не делает

- Не сохраняет и не логирует токены, cookie, email, идентификаторы аккаунта и сырые ответы API. При ошибке показывается «Нет данных», а не содержимое исключения.
- Не читает промпты, ответы агента, содержимое файлов и вывод команд. Hooks сохраняют только путь проекта / изменённого файла, статус, время и последние шаги (имена событий, не содержимое).
- Не содержит телеметрии, аналитики и автообновления.
- Не повышает привилегии самостоятельно: единственное действие с правами администратора — переключение `pmset`, и оно всегда проходит через стандартный диалог macOS. `caffeinate` прав администратора не требует.

## Известные ограничения

- Токен Cursor передаётся в cookie запроса к `cursor.com` — так же, как это делает сам Cursor. Если вы не хотите этого, не запускайте TouTou или удалите функцию `cursor_usage` из `scripts/fetch_usage.py`.
- Файл `cursor-hooks.json` генерируется локально и содержит абсолютные пути; он исключён из репозитория.
- Сборка подписана ad-hoc, без нотаризации Apple. Проверяйте исходный код и собирайте сами, если это важно.

## Сообщить об уязвимости

Откройте приватный security advisory в разделе **Security → Advisories** репозитория или напишите мейнтейнеру напрямую. Пожалуйста, не публикуйте детали в открытых issue до исправления.
